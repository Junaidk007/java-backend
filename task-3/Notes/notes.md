## java-basics-notes
_methods, strings, scanner, and non-primitive datatypes_
---

### Primitive and Non-Primitive Data Types
* **Primitive Data Types:** store simple values directly.
* **Non-Primitive Data Types:** holds a reference to an object. Created using classses.
    
### String
* String is a class in java
* It is a primitive datatype
* Stores refrences of objects
* It has a methods 

### Methods
* Methods are blocks of code that perform a specific task.
* It is created within classses, whereas functions are independed of classes.

### Scanner
* It is a built in java class used to read values from keyboard

### Why do we import packages in Java?

* We import packages in java to use built-in or user define classes from diff projects or location.

## Analogy

**Static method and Instance Methods:** <br/>
 Suppose there is a car company named BMW. This company will have something common for all their car model, such as:
- BMW Logo
- aage wala design
- ecosystem

these common things can be called as static methods.

Whereas let's say company has a car model named BMW M4. That car model will have some features, guide manual, fule type etc. That belongs to that car only not for all car model. <br> These things can be called as an instant method (belongs to particular car model/ instance/ object).
 
**next(), nextLine():**

For this let's suppose there is an examiner asking you a one-word question. It is asking a question for which you have to answer in one word. That is called next(). <br>What next does is take input till the first blank space.<br> Whereas let's say the examiner is asking question in a sentence, in line, or in a paragraph. That is called nextLine(). <br>What next line does it take input including white spaces it takes input as a sentence or line.
