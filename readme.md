# java-backend

## Day 1 Learning

Today I learned about the fundamentals of Java and programming. I learned what a high-level language and a low-level language are, and what the difference between them is. I learned about what bytecode and JVM are. I have seen what the difference is between a Compiler and an Interpreter. I understand why Java uses both a Compiler and an Interpreter for generating code. The Compiler is used to compile the Java source code into bytecode, and the just-in-time Interpreter is used to convert the bytecode into machine-level code on different machines. I also learned about the basic syntax of Java and how to write a simple program.
