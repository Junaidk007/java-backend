## java-basics-notes <br>(_operators, associativity and precedence_)

## Operators:

**Arithmetic operators**: `+`, `-`, `*`, `/`, `%` these are the operators which are used to perform mathematical computation. 

**Assignment operators**: `=` ,`+=`, `-=`, `*=`, `/=`these are the operators which are used to assign values to the variables.

**Relational operators**: `==`, `!=`, `>`, `<`, `>=`, `<=` these are the operators which are used to compare the values of the variables.

**Comparison operators**: == , !=, >, <, >=, <= these are the operators which are used to compare the values of the variables.

**Increment and Decrement Operators**: `++`, `--` these are the operators which are used to increment or decrement the values of the variables by 1. 

**Types of Increment and Decrement Operators**
1. **Postfix** : `x++`, `x--` ( use the current value of the variable and then increment or decrement it ) 
2. **Prefix** : `++x`, `--x` ( increment or decrement the value of the variable and then use it ) 

**Analogy** <br>

1. **Postfix:** Let's say you are eating Chola Bhatura. You have to take one plate in which there is one Bhatura and Chola. What you have done is you ate the Bhatura first then you asked for the second Bhatura. That was post fix. You went do the task first then the update 

2. **Prefix:** Let's say you are eating momos. You have four momos on your plate. You ask the waiter to add four more momos to your plate to make it eight momos. Then you started eating. That was what prefix increment called? You updated the value first then did the task. 

## Associativity and Precedence: 

* **Associativity** creates a hierarchy role for different operators to perform mathematical computation
* **Precedence** ensures which operands will be computed first if multiple operands lie in the same hierarchy.
